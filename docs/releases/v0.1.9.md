# v0.1.9 — 武器、物品、特性、法术四栏

按用户要求把原装备栏拆为独立武器与物品栏，和特性、法术组成四栏；每栏独立搜索、滚动和编辑。默认宽度 2:2:3:5，三个分隔条支持拖动／键盘；旧三栏比例读取时均分原装备宽度，保留其他栏宽度与旧隐藏／排序 ID，不自动写入布局。

物品和特性只显示主动可用项目。普通铠甲、盾牌、弹药、宝石、羊皮纸和纯被动特性不显示；带主动能力的魔法物品、可施放卷轴、反应和无动作消耗能力保留。剩余次数耗尽本身不隐藏主动能力，使用和资源消费仍交原生流程。现代活动不被旧 activation 字段误覆盖，隐藏或纯自动化活动不算主动入口。法术列表保持原规则。

修复空栏提示把列表挤到零高度的问题；维持 720P～4K 有效视口适配与独立确认弹窗。角色项目、被动效果及统计不修改，仅过滤 HUD 显示。

326 项离线检查及原创模拟预览。没有登录或修改线上服务器，自动部署和自动实机测试仍关闭。手动更新后重新载入客户端即可，模组仍自动启用。
