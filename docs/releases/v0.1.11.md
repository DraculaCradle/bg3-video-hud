# v0.1.11 — 按能力数量自动分配栏宽，GM 空闲不再提示

四栏现在默认按当前角色可显示的武器、物品、特性和法术数量分配宽度。内容多的分类获得更多正方形图标列，内容少的栏收窄；容量足够后不继续扩宽，减少不完整图标列的尾部空白。整体保持视口上限，内容很少时整体收窄，空间不足仍可滚动。

搜索、动作和法术等级筛选保持栏宽稳定。角色切换、物品增删和隐藏设置会重新分配；布局完成后恢复滚动与焦点，避免九环筛选移出视口。窄栏保留编辑和聚焦展开搜索。正方形图标、底部名称、角标和透明图标占位处理保持。

仍可拖动／方向键保存手动比例；双击或 Home 恢复自动分配。旧比例数据保留但默认不阻挡自动模式，不主动迁移写入。

GM 未选中 Token 且没有分配角色时安静隐藏角色 HUD，恢复原版界面，不再弹 OWNER 提示。GM 无需必须选择或分配角色；玩家权限守卫不变。
