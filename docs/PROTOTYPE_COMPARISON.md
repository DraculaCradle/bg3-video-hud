核对：2026-11-07，香港时间。依据用户提供 ZIP 中的实际入口及源码静态分析；没有执行该包或其中的安装命令。包为 `fvtt-combat-panel` 0.5.4，目标 Foundry V13／D&D5e 5.1.10，与本项目的 V14／6.0.6 不同。附件与此前参考包相同，没有新增版本差异。

以下交互改动属于当前开发版，**尚未发布或安装到服务器**。公开 Release 仍为 v0.1.2。用户已改为人工验收，本轮仅做离线模拟回归，不登录 Foundry，不发布、不部署、不重启服务或修改其他世界。

## 手感差异的具体来源

| 项目 | 半成品当前路径 | 已发布 v0.1.2 | 本次开发版 |
| --- | --- | --- | --- |
| 普通单一活动／戏法 | 跳过明确的唯一活动和无必要的施法方式页，进入目标选择 | 即使只有一个活动，也要选活动、再点使用 | 无环阶／来源决策时，直接进入目标／原生流程 |
| 单一活动的等级法术 | 点击法术后显示施放环阶／来源 | 先点唯一活动，再显示施放方式 | 直接显示环阶／来源，不自动替用户选择消费资源 |
| 多活动物品 | 明确选择活动 | 明确选择活动 | 保留，避免猜测单／双手、攻击或其他用法 |
| 高级操作 | 按具体页面提供选项 | 活动、重复次数和原生模式每次都进入完整流程 | 底栏“详细”可恢复完整流程；默认减少常用操作步骤，不持久化额外偏好 |
| 取消 | Esc／取消返回列表，地图阶段支持取消 | 地图 Esc 可用；栏内选择主要靠按钮 | 栏内活动／施法／分配也支持 Esc，系统弹窗保留自己的 Esc 行为 |
| 多目标交互 | 逐个点选，射线允许重复分配 | 按用户要求默认框选后自动选中目标 | 保留用户确认的范围框选；不擅自改回原包逐个点选 |
| 其他 HUD | 包的清单没有 BG3 必需项 | 安装声明和启用检查要求两个 BG3 模组 | 取消硬依赖，已有 BG3 可共存；关闭后返回 Foundry 或原已启用 HUD |

操作步数只比较 HUD 自己增加的步骤；原生配置、目标模板、攻击／伤害掷骰与消费确认仍可能出现。以单一普通攻击为例，旧 HUD 为“点图标 → 选活动 → 点使用 → 选目标”，开发版为“点图标 → 选目标”。快捷路径仍通过原有的角色权限、活动新鲜度、场景变化、目标可见性与原生使用守卫，不跳过系统消费或自己扣资源。

## 独立运行的实际范围

- 必需：现有 Foundry V14、D&D5e 6.0.6、本模组；当前仍只在 ModsTest 工作。
- 不依赖 BG3 API、源码或持久化 flags。取消清单强制依赖、运行时启用条件、安装器的强制安装要求，并同步未来实机流程的相应条件；世界、会话、系统／版本、备份和恢复检查保留。
- 本 HUD 挂载期间，自己的 body 类临时隐藏 Foundry 原生快捷栏及可选 BG3 外壳，避免重叠；关闭／卸载／失去可用角色后恢复原显示规则。不会更改快捷栏内容、原生快捷键、其他 HUD 的设置或模组启用状态。
- 新安装包拒绝必需 HUD 模组；已知旧版 BG3 清单仅在既有树、已验证备份及事务恢复路径中识别。旧版升级后仍可回滚，清单变化仍须维护窗口，不允许自动热替换。
- 当前线上 v0.1.2 仍需要旧依赖。请勿据此说明提前卸载线上 BG3；独立能力需要之后明确发布／安装的新版本。

## 尚未追平或有意不同的部分

| 原包中的实现／入口 | 当前状态 |

| 图像化的大环阶／来源卡片及余量排列 | 本项目有环阶／来源按钮、余量与法术位图形，卡片视觉与信息层级仍不同 |
| 结束回合入口 | 尚无等价按钮；本次没有借移除依赖而宣称补齐 |
| 护盾术等反应施法相关代码 | 尚无等价反应提示；原包具体工作流也需单独核实，不能按文件存在即认定完整可用 |
| 魔法飞弹和更细的豁免／条件预测 | 当前保守使用原生流程与基础估算，不复制面向旧系统的公式或伪造完整规则支持 |
| 删除免费来源 | 当前提供创建、编辑、启用／停用，没有不可逆删除入口 |

因此，减少点击和独立运行解决了两项明确差异，**不等于已完全追平原作者的交互手感**。后续可以根据用户人工反馈继续处理分栏、卡片信息和其他入口。未假定拿到 ZIP 就获得公开复制其源码／样式的许可；本次为独立实现，没有把附件、源码、视频、规则书或玩家数据放入公开仓库。
