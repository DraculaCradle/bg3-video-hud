# v0.1.5 — 恢复任意世界的手动启用入口

修复仅在 ModsTest 注册设置导致其他世界找不到“启用 BG3 视频界面”的问题。现在可在任意世界手动启用，默认关闭，仅影响当前客户端。Foundry V14 / D&D5e 6.0.6 的兼容性与角色权限检查保持生效。

操作：世界内“管理模组”勾选“BG3 视频界面”并保存，重新载入后打开“配置设定 → BG3 视频界面 → 启用 BG3 视频界面”。安装、世界内启用模组、客户端打开 HUD 是三个步骤。

自动部署和自动实机测试仍关闭；部署及测试脚本只允许 ModsTest，没有自动修改其他世界或服务器服务。人工更新后重新载入客户端。
