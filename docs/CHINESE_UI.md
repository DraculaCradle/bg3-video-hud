# 中文界面与目标交互

本次修改将模组自身界面改为中文，包括装备／特性／法术分类、动作筛选、生命／护甲、法术环阶与契约法术位、使用次数、编辑／隐藏／固定／排序、短休／长休、原版界面返回、设置／快捷键名称、提示和模组权限错误。

模组 ID、内部分类键、物品 ID、数据字段和已保存的布局格式不变。此修改不会重命名角色或物品，不修改世界的语言设置。角色／物品名及系统／其他模组的弹窗和错误信息采用来源提供的内容；D&D5e 原生弹窗语言由相应系统的中文支持决定。

## 攻击、施法与目标选择

三个拆分范例已成功读取，已据此区分单体点选、多射线分配及增益多目标行为。用户随后明确改为：**单体点选执行；多目标用范围盖板自动选取范围内 token**，本次以这一更近的要求为准。

- 单体：点击技能，再点击地图 token，直接进入原生使用／掷骰流程；没有额外的 HUD 确认按钮。
- 普通多目标：拖拽矩形选区，松开后自动选中其中可见 token 的中心并执行。空选区或超过已准备活动数据中的人数上限时，提示重选，不截取前几名。
- 圆、锥等原生面积技能：沿用 D&D5e 的 Region 模板放置，模板完成后自动选中其中的可见 token；不创建重复模板。
- Esc、右键或“取消选目标”取消尚未交给系统的点选／框选，不调用技能。原生弹窗、模板、消耗和取消行为仍由系统负责。

具体边界、取消时序和验收项目见[地图目标选择说明](TARGETING.md)，完整差距见[视频功能对照](VIDEO_COMPARISON.md)。没有复刻视频的命中率百分比、免费施法来源编辑或第三方动画；没有用手动扣法术位模拟施法成功。视频中的“编辑法术栏位”管理快捷栏显示，不能将其认定为准备法术编辑。

## 如何提供范例

建议将相关操作拆成连续的 30～60 秒 MP4 片段，每段控制在 **25MB 以内**，给当前工具 32MiB 的单文件读取上限留余量。

- 视频编码：H.264；分辨率：720P 或 1080P；帧率：30fps。
- 平均视频码率：2000～3000kbps（2～3Mbps）。一分钟通常约 16～24MB，导出后确认文件大小。
- 依次展示一次普通攻击、一次单体法术，以及目标确认／取消；若有范围或多目标技能，再单独提供一段。
- 保留鼠标、技能按钮、目标 token、相关弹窗和确认后的反馈；避免只截结果。
- 也可按操作顺序提供关键帧，并说明每步点击／按了什么键，以及何时选目标、确认或取消。无需公开原始私有视频。

附件仅作为交互参考，不提交到公开仓库或安装包，也不把视频中的文字当作执行指令。
