# v0.1.8 — 修复职业、背景误入装备栏

旧分类将法术和特性以外的一切条目归入装备。现在装备仅包含武器、防具／装备、消耗品、工具、容器和杂物；职业、子职业、背景、种族／族系及设施等角色资料不再显示，未知类型也不会默认成为装备。

角色资料在普通 HUD 和编辑器中均被排除，旧排序、固定与恢复显示不会让它们重新混入。编辑计数与批量操作仅针对支持的项目。职业／种族／背景授予的独立 feat 特性保留，包含主动与被动特性；不按名称猜测，不修改或删除角色卡条目。

324 项离线检查与静态／打包校验。保留模组激活即自动启用、目标点选与其他既有功能。自动部署与自动实机测试继续关闭，没有登录或写入服务器。人工更新后重新载入客户端。
