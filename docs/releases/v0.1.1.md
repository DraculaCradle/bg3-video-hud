## 安装与更新

继续使用原地址，在 Foundry 的模组管理界面手动检查更新：

```text
https://github.com/DraculaCradle/bg3-video-hud/releases/latest/download/module.json
```

目标为 Foundry VTT V14、D&D5e 6.0.6，依赖已安装并启用的 bg3-hud-core / bg3-hud-dnd5e ≥0.8.0。当前模组仍只在标题为 ModsTest 的测试世界工作；不扩大其他世界的启用范围。

本发布包含 bg3-video-hud.zip、module.json、SHA256SUMS 和独立 Linux 安装脚本。发布操作不自动部署、不重启 Foundry、不修改世界或其他模组；自动部署保持关闭。
