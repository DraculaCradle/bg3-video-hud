# v0.1.12 — 能力少时保留空位，HUD 总宽不缩小

按用户澄清，数量自适应只改变武器／物品／特性／法术四栏的内部空间分配。HUD 总宽仍由视口、侧栏和既有上限决定；能力总数少或为空时不再缩小整体，允许空位和尾部空白。

内容多的分类仍获得更多空间；基本图标列分配后，余量按数量权重留在各栏。搜索、筛选、增删项目和切换角色不改变同一视口下的总宽，手动分隔条也只调整内部比例。

保留正方形图标、底部名称、透明图标大字处理、主动筛选、滚动／焦点恢复、自动启用与 GM 空闲不警告。
