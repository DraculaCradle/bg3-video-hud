# 范例视频与当前功能对照

2026-11-07 的原作者 0.5.4 有效入口、离线只读渲染及 v0.1.4 完整对照见[原作者半成品对照](PROTOTYPE_COMPARISON.md)。本页视频观察仍是 2026-11-06 的历史参考；v0.1.9 按后续用户要求改为四栏和主动项目筛选，当前布局见 [自适应说明](COMPACT_HUD.md)。

核对日期：2026-11-06。基于用户提供的三个片段，本轮补齐前次表中尚未实现的 HUD 入口与交互；操作见[视频功能补齐](COMPLETE_HUD.md)。私有视频、截帧、玩家数据和规则书正文不进入仓库或安装包。

v0.1.2 包含下列实现。**代码与离线检查通过不等于 Foundry 实机验收通过。**

| 视频中的内容 | 当前实现 | 边界 |
| --- | --- | --- |
| 头像与三个分类图标区 | 自适应头像、生命／护甲与独立滚动 | 720P～4K 流式布局，独立设计，不逐像素复制 |
| 血条、临时生命与法术位标记 | 生命条、临时生命提示、普通／契约位数字及图形标记 | 只读原生数值 |
| 原栏内活动选项和返回 | v0.1.3 按用户要求改为独立弹窗，保留返回与取消 | 确认后先关闭弹窗，原生配置和掷骰窗口保留 |
| 选择本次施放环阶及余量 | 本次法术位卡片与升环配置 | 区别于列表环阶筛选，原生最终选择有效 |
| 免费来源新增／编辑、次数和恢复 | 专用原生来源特性编辑器，启用／停用、短休／长休／每日恢复字段 | 显式保存才写当前角色；真正消耗／恢复待实机核验 |
| 富文本物品／法术说明 | 原生 richTooltip 及描述回退，完整名称和格式 | 过滤危险 HTML，隐藏 secret；不保证每个自定义系统字段都可预览 |
| 搜索 | 各分类名称搜索，支持中文输入法 | 不全文检索规则书正文 |
| 分类齿轮、显隐与排序 | 分类编辑、逐项显隐／固定、拖动／键盘排序 | v0.1.4 分组齿轮使用独立编辑弹窗 |
| 全选、清空、自动全部、数量、保存／取消 | 分类与搜索范围批量操作，整次草稿保存／取消 | 不修改法术准备状态或其他用户布局 |
| 指针图标、连线、编号及结算进度 | 目标图标／连线、分配编号与结算状态 | 仅当前可见场景对象，输入取消会清理 |
| 命中率、优势与平均伤害 | 原生数据的基础估算、基础距离／视线提示 | 无观察权限不泄露目标属性；未知规则不编造结果 |
| 灼热射线重复分配和撤回 | 默认框选目标后轮流分配；可选手动重复分配、撤回；一次原生施放后逐条攻击／伤害 | 灼热射线／魔能爆明确 identifier 配置；其他重复显式设置，不把任意多目标当成多射线 |
| 祝福术／援助术逐个选人、未满人数提前施放 | 按用户新要求，框选后自动选择范围内目标并执行；允许少于人数上限 | 有意替换视频手动队列，超过上限重选 |
| 动作／附赠动作／反应指示 | 原生使用观察记录、当前战斗回合位置更新、忙碌反馈 | 不是权威剩余次数，不限制额外动作 |
| 角色卡、短休和长休 | 原生入口保持可用 | 资源恢复由系统处理 |
| 多人概览与浮动 token 状态 | 权限过滤的队伍概览、当前场景角色选择和浮动状态 | 自行实现入口，不复制未知第三方部件 |
| 3D 骰子、动画、伤害／治疗与聊天效果卡 | 保留原生钩子、第三方启用状态、无 AA 时提供自己的轻量 VFX，伤害用原生聊天卡 | 视频出现 AA／Sequencer 提示；特定动画素材和第三方组合不是本扩展可单独保证的能力 |

视频 01 的“编辑特性栏位”“编辑法术栏位”管理快捷栏显示。不能将其认定为 D&D5e 的准备法术编辑；本实现也不修改准备状态。
