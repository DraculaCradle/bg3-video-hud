## 用户要求优先的交互

- **确认与资源选择在独立弹窗**，不再占用某一栏；这是用户对原版栏内选择的明确修改。
- 多目标使用用户指定的框选范围，松开后自动选中范围内可见 Token；不改回原作者逐个点选。超过上限会提示重新选择，不静默截取。
- 720P～4K 随有效 CSS 视口有界增长；保留 125%／150%／200% 缩放下的紧凑布局。不是照搬原版固定像素或无上限放大。
- 保留独立运行、原版界面返回、动作筛选、固定法术与“详细”选项。全部中文标签，原生物品名称依角色内容。
- 布局保存只写自己的用户布局字段，不迁移原作者或 BG3 的角色 flags。

## 必须区分的验证边界

已检查的是原版有效入口、独立实现的界面结构和离线行为，**不是逐像素复刻承诺或 Foundry 实机验收**。用户已停止自动实机测试；本次未登录服务器、写世界数据或重启服务。

预测使用 D&D5e 当前准备数据与原生只读修正接口。无法确定的规则显示未知；不执行效果中的任意条件表达式，不推测隐藏目标数据。第三方专属条件、CPR 特定自动化和免疫等最终仍由安装的原生工作流裁定，不能把基础概率当成完整自动化预测。开启 Midi-QOL 时，自定义重复次数／手动逐发分配须在其原生流程操作，本模组不会另行重复结算。

护盾术接口按公开 Midi-QOL 源码核对；没有取得其与用户实际安装组合的实机证据。原版 V13 专属自动化不是整包复制进 V14。不同版本／定制物品的行为必须人工验收，不把离线 mock 的通过宣称为这些组合全部通过。
