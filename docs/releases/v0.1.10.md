# v0.1.10 — 隐藏透明图标背后的大字，保持格子正方形

有图标时隐藏图标背后的名称占位大字，避免透过透明图片显示。按用户澄清，底部名称文字保留，次数与环阶角标也保留；图片失败恢复文字回退，完整名称／说明仍可悬停或键盘查看。

图标格子不再横向铺满栏宽而变成长方形，宽高保持1:1；原图等比放入，不拉伸。窄栏和编辑模式继续保持方形，原有720P～4K自适应、四栏、主动项目筛选和自动启用不变。

327项离线检查及原创模拟截图。没有连接或修改线上服务器，自动部署与自动实机测试继续关闭。通过原manifest地址人工更新后重新载入客户端即可。
