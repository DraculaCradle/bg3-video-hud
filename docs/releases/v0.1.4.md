# v0.1.4 — 原版布局对齐与武器选目标修复

修复部分近战武器的攻击活动目标类型为空时跳过地图选目标的问题：点击武器后先点选可见目标，再调用原生使用；取消不消耗。Midi-QOL 已启用时，常规攻击交由其继续处理，不再被重复结算保护误拦截。

按用户提供的原作者 0.5.4 有效入口核对并独立重做分离式布局：圆形头像、AC／生命条、三块金边技能栏、上方资源条、右侧圆形短休／结束回合按钮。默认 2:3:5，支持拖动／键盘调整、撤销、保存及恢复。技能显示短名称、环阶、余量，仍保留完整说明；适配 720P～4K 的有效视口。

分组编辑、活动／施放环阶／免费来源及目标分配使用独立弹窗。补充来源删除确认、SRD 魔法飞弹分配、目标锁定框和豁免失败率预览，以及可选 Midi-QOL 护盾术反应资源选择。保持无 BG3 HUD 必需依赖。

自动部署和自动实机测试关闭。离线测试、模拟截图不等于用户服务器验收；第三方条件／定制活动的最终结算以原生系统为准。手动更新后重新载入客户端，优先人工检查普通武器点击选目标、取消、技能栏布局和资源弹窗。仅 ModsTest，服务器服务／其他世界配置不变。
