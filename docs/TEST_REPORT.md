本次新增重点：

- 物品多／法术多时对应栏获得更多整列，稀疏角色整体收窄；窄视口几何预算不溢出，异常输入有检查。自动计算不写 flags，旧比例只读保留；手动调整有显式标记，Home 返回自动。
- 实际 DOM 验证角色切换、同角色新增物品后重新分配、搜索／动作／等级筛选不跳宽，以及 GM 不分配角色、取消选择时无通知且原 HUD 可用。
- 自动模式下所有有效视口检查栏内尾部余量不足12 CSS px（预留滚动条／舍入）；保持整列方形和可达控件。几何完成后恢复滚动，九环筛选和真实滚轮回归通过。
- 更新五档原创模拟预览与弹窗，以下高度不随物品数量增长：720P约224px、4K约414px；宽度随当前角色数量变化。

- 透明图标存在时隐藏背后的 initial 大字，不隐藏底部名称；ARIA、title、键盘焦点后的完整 tooltip 保留，角标不隐藏。图片失败后恢复文字回退，不写布局 flags。

- 旧三栏比例只读转换为四栏，保留排序和隐藏 IDs；第三分隔条单独键盘验证，其他两栏宽度保持。
- 四个列表的几何／滚轮／键盘检查覆盖 720P～4K、有效 CSS 缩放及空栏；修复空提示导致列表高度为零的问题。五档原创模拟预览及弹窗截图已更新，720P 仍约 224px 高。

- 四栏：武器、具备主动使用的物品、主动特性、法术。被动装备／特性、弹药与角色资料排除，主动卷轴／反应／无动作能力保留；混合活动、隐藏助手与耗尽次数有模型回归。
