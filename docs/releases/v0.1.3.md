# v0.1.3：独立 HUD 与弹窗确认

- 无需安装 BG3 HUD Core／D&D5e；已有 BG3 可共存，不更改其设置或启用状态。
- 活动、施放环阶／来源及手动目标分配改为独立弹窗，HUD 三栏保留物品列表。弹窗按有效视口限制宽高、内部滚动，覆盖 720P～4K 和 640×360 等效缩放视口。
- 支持 Esc、取消、关闭、键盘 Tab／Enter；嵌套来源窗口可独立退出。切换角色／token 会取消待确认选择；弹窗先关闭，再进入地图或系统使用流程。
- 普通唯一活动和无需选来源的戏法直接使用；等级法术保留资源选择，多活动仍明确选择。底栏“详细”保留完整选项。
- 结算进度在底栏简要显示，保留“停止后续”；原生配置、掷骰、消费和聊天仍由系统处理。
- 无 BG3 安装、旧清单备份／回滚及旧事务恢复通过离线回归；清单变化仍要求管理员维护，不允许自动热替换。
